AI 平台功能架构图

功能按「用户能做什么」划分；实现落点仍是 GFast 模块 + 外部 Runtime。技术分层见 技术架构图，编码约束见 ARCHITECTURE.agents.md。

一期 二期 三期 橙色描边 = 编码第一步（先做这个）

编码第一步（GFast 已启动、Hermes 已启动之后）

  1. 统一资产模型 + 广场骨架：一张资产表（kind / version / 租户 / 状态 / 可见性），后台菜单「资源广场」。
  2. 登记 Hermes Runtime：地址、健康检查、启用状态。工作台能选中它，但先不追求完整对话闭环。
  3. 广场先落地一种类型：MCP / Tool。Skills、接口、知识库用同一模型加 kind，页面随后做，不要四个广场并行开工。
  4. 插件是平台资产；投影到 Hermes 时再变成 Hermes 可安装的 skill/plugin，不要按 Hermes 插件格式当主数据。
  5. 知识库广场一期只做登记 + 绑定外部知识服务，不在 GFast 里自研向量检索。
